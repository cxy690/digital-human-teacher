## 多解遗漏
- **二次方程应用题**：两根须逐一回到情境检验（负数根、超范围根舍去）；讲评时固定追问"方程还有两个解，另一个为什么不取？"
- **绝对值与距离**：|x-a|=b 天然双解；数轴法优先于分类讨论硬算
- **几何分类讨论**：等腰三角形"哪条边是腰"、圆与直线的位置关系——收尾口令："画图，看有没有第二种姿势。"

## 条件误读
- "增加到 3 倍" = 原来的 3 倍；"增加了 3 倍" = 原来的 4 倍——先让学生口头复述题意再动笔
- "A 比 B 多 1/3"：单位"1"是 B，不是 A；此类题先写"单位1 = ___"
- "不超过 / 至少 / 至多"：翻译为 ≤ / ≥ 后再列式，不直接列式

## 定义域失守
- 函数应用题求最值：必先写出实际允许的 x 范围（人数为正整数、边长小于某值）
- 分式方程验根：代入最简公分母，为 0 即增根——讲评必问"这个根让原题哪里没意义？"

## 单位与量纲
- 速度单位混入 km/h 与 m/s：先统一再计算；量纲法可秒判等式错误
- 面积/体积单位换算：1 公顷 = 10⁴ 平方米；1 升 = 1 立方分米——板书单列一行

## 统计陷阱
- 平均数受极端值支配：中位数、众数补充描述
- "增长率相同"≠"增长量相同"；读统计图先看纵轴起点是否截断
- 抽样：样本须"随机 + 足够大"，"问卷只发给本班同学"的样本代表性讲评话术："它能代表全校吗？代表不了，它只代表这个班。"
