# core/intent — 意图决策层（会话入口闸门）

会话入口第一道闸门：判简单意图、对复杂/多意图做拆分与转交决策。**纯决策层**——不持状态、不调其他执行者、不参与消息总线，因此不属于 `agents/` 层（由 `agents/router/` 迁来）。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `__init__.py` | 包门户；`IntentAnalyzer` 透出 `route` / `route_async`，可原地替换 Supervisor 里的 router。 |
| `analyzer.py` | 两级判定：一级轻量规则（微秒级零成本）覆盖常见输入；二级小模型只在规则判不准 / 复杂多意图时调用；多意图按句末标点 + 长连接词优先切分。 |
| `classifier.py` | 意图分类小模型：规则判不准 / 复杂多意图时兜底复核；`sub_questions` 要求照原话拆（会原样喂给 TeacherAgent）。 |

## 设计要点

- **保首响 1.2s 的预算纪律**：高频输入（控制 / 闲聊 / 单一提问）走规则直判，不占首响预算；只有规则判不准才付模型调用成本。
- **「分类可以不准，但绝不能拖慢或阻断答疑」**：失败 / 超时 / 输出非法一律返回 `None` 回退规则结果。
- **多意图拆分保留原话**：润色会改掉学生原意，`sub_questions` 一律原文。
- **`unknown` 不作为模型输出**：判不出应返回空，让上层保留规则判定，避免模型用 `unknown` 覆盖掉本来可用的规则结果。
