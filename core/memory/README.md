# core/memory — 学情长期记忆

跨会话记住「这位学生」的错题、薄弱点与偏好，下次讲解时自然带出。**与「教师经验」正交**：经验按老师存（老师会了什么），记忆按学生存（学生哪儿不会）。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `__init__.py` | 包门户；读走 `build_memory_prompt_for`（teaching_layers 装配时）、写走 `MemoryWriter`（判题/答疑结束时）。 |
| `models.py` | 记忆条目模型：kind / 权重 / 时间衰减 / 命中次数；文本限 2~80 字。 |
| `store.py` | 按学生分文件的 append-only JSONL 存储（`data/memory/`）；相似度 0.85 去重累加；`forget()` 物理删除。 |
| `prompt.py` | 把检索到的记忆渲染成可注入的 system 片段（层序：身份→契约→学科→人格→**学情记忆**→经验→本轮输入）。 |
| `writer.py` | 记忆写入方：规则写入（默认开、零成本，判错即记）+ 模型蒸馏（默认关，按间隔节流）。 |

## 设计要点

- **按 student_id 物理隔离**：同名两个孩子是两个人，串号是最不能出错的事；存储按学生分文件是硬边界。
- **JSONL 而非 DB**：每次一行快照自带审计、追加写不怕写一半崩、坏行跳过、纯文本可人工修正。
- **隐私合规**：`DELETE /api/memory/{student_id}` 一次性物理删除（面向未成年人的合规要求）；`POST /api/memory/status` 可停用单条（记错时的止损）。
- **注入位置有讲究**：记忆排在人格之后——「越靠后影响力越强」，具体到这堂课的信息应压过抽象教学法；要求自然带出、不罗列、不贴标签，单条最多渲染 60 字。
- **默认关蒸馏的理由**：第一次课问不出稳定特征，高频蒸馏只把额度花在噪音上；规则写入零成本且判题结果已在手。
- **旁路增强**：记忆链路异常只告警绝不阻塞课堂；`MEMORY_MAX_ITEMS=0` 表示不限、永不自动淘汰（要清空走 DELETE 接口）。
