# core/planning — 回合自主规划

模型作答前先产出结构化执行计划（目标 + 步骤 + 建议工具），把原先写死在代码里的策略（`_is_complex` 关键词表、固定 delegation 话术）交回模型。`AGENT_PLANNER_ENABLE` 控制。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `__init__.py` | 包门户：`get_turn_planner()`。与 intent 分工——intent 是**闸门**（判类别），planner 在闸门之后回答「这回合打算怎么做」。 |
| `planner.py` | 回合规划器：调用模型产出计划；动作词表 `ACTIONS` 与工具表 `TOOLS` 白名单校验；超时/失败回退 `rule_plan()`。 |

## 设计要点

- **计划不是硬指令**：工具调用仍由模型在 ReAct 闭环现场决定；计划只进 `context_notes`，并留可回溯痕迹（`turn.meta["turn_plan"]`）。
- **三条硬约束**：超时（默认 6s）/ 不可用一律回退规则计划；计划不当硬指令；计划必须可序列化回溯。
- **「像方程」判据刻意写宽松**：宁多建议一次求解（多花一次工具调用的成本可忽略，漏解才伤体验）。
- **不认识的动作降级 explain**：白名单校验防模型自由发挥出无法执行的计划。
