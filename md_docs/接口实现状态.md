## 待接入真实实现的关键点
- 音视频：当前用浏览器 `getUserMedia` + WebSocket；量产建议接 WebRTC SFU（Agora/LiveKit）。
- 实时语音：当前为「音频片段 → ASR」；量产建议流式 ASR + 服务端 VAD + 流式 TTS。
- 图片圈画定位：当前为区域示意；量产建议由 VLM 返回精确 bbox 或 OCR 行框。
