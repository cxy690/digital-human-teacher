# 算力云部署指南（1对1 教学AI · 拉取即跑）

> 目标：把整个项目拉到一台 **Linux GPU 算力云主机**（优云智算 / AutoDL / 阿里云 / 腾讯云 GPU 等），
> 跑起「1对1 实时答疑教学AI」的全套能力：**答疑大脑（在线 API 或本地 AWQ）/ FunASR（听）/ CosyVoice 3（说，克隆老师音色）/ MuseTalk（对口型，多老师）**。
> 产品形态为 **1对1 实时答疑/辅导**（非大班直播课）；相关：[`README.md`](README.md)、[`代码地图.md`](代码地图.md)、[`本地开发联调.md`](本地开发联调.md)。

## 一、部署拓扑与端口（单机多服务）

```
[主应用 · CPU]  server.app（1对1 答疑编排/网关/白板/麦控）   :8001   ← 学生端入口
      │  .env 端点全部指向 127.0.0.1 ↓
[答疑大脑]  三种形态，任选其一：
   ├─ 在线 API（默认推荐·质量优先）  DeepSeek 等 OpenAI 兼容端点（不占本机显存）
   ├─ 本地 AWQ（离线·断网可用）      scripts/llm_engine_local.py（transformers+AWQ）  :8100
   └─ 本地 vLLM（可选·默认关闭）     Qwen3（OpenAI 兼容）                             :8100
[FunASR]      语音识别（学生提问，默认 SenseVoiceSmall）        :10095
[CosyVoice 3] 语音合成（克隆老师音色；2/3 引擎自动挑版本；edge-tts 作零依赖兜底） :8090
[MuseTalk 1.5] 实时对口型数字人（**多老师**按学科懒加载底片）    :8012
（可选 Wav2Lip 兜底）                                            :8011
[公网隧道]    cpolar 或 cloudflared（把 8001 暴露成 HTTPS）      随机域名
```

- 主应用**不吃 GPU**，纯 CPU；GPU 全在各模型引擎。
- 每个引擎独立运行环境（`.venvs/*` 或平台 conda env），互不污染；起不起由开关控制。
- **当前推荐的默认组合**：主应用 + FunASR + CosyVoice 3 + MuseTalk + **在线答疑 API**；
  需要断网自研时才切「离线模式」拉起本地 AWQ 大脑。

## 二、云主机选型建议

| 场景 | GPU | 显存 | 系统内存 | 磁盘 |
| --- | --- | --- | --- | --- |
| **推荐·单卡满配**（本地 AWQ 大脑 + CosyVoice 3 + MuseTalk + FunASR 同驻） | **RTX 4090 48G ×1**（sm_89） | 48GB | 64GB | 200GB |
| 轻量（在线答疑 API + FunASR + CosyVoice 3 + MuseTalk） | RTX 4090 24G / A10 / V100S ×1 | 24-32GB | 32GB | 100GB |
| 生产（多学生并发答疑） | 4090/A10/L40S ×N，按并发横向扩容 | 每卡 24-48GB | — | — |

> **RTX 4090 48G（sm_89）**：FlashAttention 原生支持（无需 xformers 回退），48G 显存可让
> CosyVoice 3 + MuseTalk + FunASR（+ 本地 AWQ 大脑）**全栈同驻一卡**（≈20-28G），是单机满配首选。
> V100S(32G, sm_70) 亦可跑实时栈，但要用在线答疑大脑或 AWQ，且 vLLM 需走 xformers 回退。

## 三、云上需要下载什么（核心清单）

`deploy/cloud/download_models.sh` 会下载 **Qwen3 / CosyVoice 3 / MuseTalk（可选 Wav2Lip）**，
统一到 `models_zoo/`（国内默认 hf-mirror + ModelScope，可用 `USE_HF=1` 切官方）。

| 组件 | 仓库（git clone） | 权重来源 | 磁盘约 | 运行显存约 |
| --- | --- | --- | --- | --- |
| **答疑大脑·在线** | 无 | 不用下载，填 `LLM_API_BASE/KEY`（如 DeepSeek） | 0 | 0 |
| **答疑大脑·本地 AWQ** | 无（本项目自带服务） | ModelScope `Qwen/Qwen3-8B-AWQ` 或 `Qwen/Qwen2.5-7B-Instruct-AWQ` | 5-8GB | ≈7-8G |
| **答疑大脑·vLLM（可选）** | 无（vLLM 直载） | ModelScope `Qwen/Qwen3-8B`（或 `Qwen3-4B`） | 8B≈16GB | 8B FP16≈16G |
| **FunASR** | 无（pip 装） | 运行时自动下 `iic/SenseVoiceSmall`（默认，自带 VAD/标点） | ≈1GB | 1-2G（可 CPU） |
| **CosyVoice 3**（推荐） | `github.com/FunAudioLLM/CosyVoice` | ModelScope `FunAudioLLM/Fun-CosyVoice3-0.5B-2512` | ≈6GB | ≈4-6G |
| CosyVoice2（回落） | 同上（仓库自带两版代码，按权重的 yaml 自动挑） | ModelScope `iic/CosyVoice2-0.5B` | ≈8GB | ≈4G |
| **MuseTalk 1.5** | `github.com/TMElyralab/MuseTalk` | HF `TMElyralab/MuseTalk` | ≈10GB | 4-6G |
| Wav2Lip（可选兜底） | `github.com/Rudrabha/Wav2Lip` | HF `camenduru/Wav2Lip` | ≈1GB | 2-4G |
| **Python 依赖** | — | pip：torch(对应 CUDA)/funasr/各仓库 requirements | torch≈8GB/环境 | — |

> ⚠️ `download_models.sh` **只覆盖 Qwen3 / CosyVoice / MuseTalk / Wav2Lip**；
> 若用「本地 AWQ 大脑」，AWQ 权重需另行下载：
> `python -c "from modelscope import snapshot_download as d; d('Qwen/Qwen2.5-7B-Instruct-AWQ', local_dir='models_zoo/Qwen2.5-7B-AWQ')"`。

### 需要你上传到云主机的素材（多老师，**核心新增**）

每位老师 = 一个学科，放在 `data/teachers/<学科key>/`（key 与 `config/subjects.py` 一致）：

```
data/teachers/
├── chinese/          # 例：语文老师
│   ├── talk.mp4      # 授课底片（正面半身、单人脸、24fps、≥1280x720）
│   ├── voice_ref.wav # 参考干声（CosyVoice 克隆音色用；可选）
│   └── teacher.json  # 档案：voice_ref_text / voice_engine / voice / eye_points / blink 等
├── math/  english/  physics/ ...   # 其余学科同理
```

- **最少只放 `talk.mp4`** 即可上课（音色自动用该学科的 edge-tts 兜底音色）；
- 想克隆音色则补 `voice_ref.wav` + `teacher.json.voice_ref_text`（例：`"voice_engine": "edge"` 表示走零依赖的微软云音色）；
- 上传方式：本地 `python scripts/sync_cloud.py`（见第六节）或手动 `scp`。

## 四、三步部署

```bash
# 0) 拉取项目到云主机，进入项目根
cd <remote-root>        # 目录随平台；脚本按项目根自定位

# 1) 开机自检（确认镜像 torch 认得这张卡 / 架构 kernel 可用）
bash deploy/cloud/check_gpu.sh

# 2) 基础环境（系统依赖 + 主应用/FunASR venv，继承平台 torch）
bash deploy/cloud/setup.sh

# 3) 下载模型仓库与权重
bash deploy/cloud/download_models.sh
#   （本地 AWQ 大脑需另下：见第三节说明；只跑在线答疑 API 可跳过）

# 4) 生成云端配置 + 一键启动
cp deploy/cloud/env.cloud.example .env
#    编辑 .env：
#    * 在线答疑：LLM_PROVIDER=openai / LLM_API_BASE=https://api.deepseek.com/v1 / LLM_API_KEY=... / LLM_MODEL=deepseek-chat
#    * 离线答疑：见下方 switch_mode.sh（自动写 .env 并重启主应用）
#    * 多老师音色无需在此填 TTS_REF_*，由 data/teachers/<key>/ 自动提供
bash deploy/cloud/start_all.sh

# 停止全部
bash deploy/cloud/stop_all.sh
```

启动后 `start_all.sh` 逐个探活打印 `[OK]/[WAIT]`；日志在 `deploy/cloud/logs/*.log`。

### 在线 / 离线「答疑大脑」一键切换

```bash
bash deploy/cloud/switch_mode.sh online     # 切在线：DeepSeek API（质量优先，需外网）
bash deploy/cloud/switch_mode.sh offline    # 切离线：自动拉起本地 Qwen2.5-7B-AWQ（断网可用）
bash deploy/cloud/switch_mode.sh online --no-restart   # 只改 .env 不重启
```

- 片段文件：`deploy/cloud/mode_online.env`（在线）/ `mode_offline.env`（离线），脚本会逐行并入 `.env` 后重启主应用；
- **语音识别（耳朵）已永久本地化**（FunASR/SenseVoiceSmall），此脚本只切「大脑」。

## 五、日常运维（新增）

| 操作 | 命令 | 说明 |
| --- | --- | --- |
| 全栈启动 | `bash deploy/cloud/start_all.sh` | 引擎 + 主应用 + 公网隧道 |
| 全栈停止 | `bash deploy/cloud/stop_all.sh` | 按 `logs/pids.txt` 结束 |
| **关机前**（停服务+隧道） | `bash deploy/cloud/pause.sh` | 之后可放心点云控制台「关机/停止」（勿点释放/删除） |
| **开机后**（幂等恢复） | `bash deploy/cloud/resume.sh` | 已有则跳过；自动起 cloudflared 隧道并打印新公网链接到 `logs/public_url.txt` |
| 只重启主应用 | `bash deploy/cloud/restart_app.sh` | 改 `config/ core/ server/ clients/` 后用，不动已加载模型 |
| 只重启 TTS 引擎 | `bash deploy/cloud/restart_tts.sh` | CosyVoice 2/3（自动挑 `pretrained_models/` 里的版本），fp16 关闭（半精度会退化成噪声） |
| 只重启数字人引擎 | `bash _restart_engine.sh` | 改 `scripts/avatar_engine_*` 或换底片后用 |
| 登录自动恢复（可选） | 见 `deploy/cloud/_bashrc_hook.sh` | 追加进 `~/.bashrc`，登录时若主应用未在跑则自动 `resume.sh` |

> 重启类脚本都用「扫 `/proc/*/cmdline` 精确匹配」的方式杀旧进程（镜像里没有 `fuser`，
> `pkill -f server.app` 会误杀调用方 shell），照抄即可，勿改回 pkill。

### 公网隧道（HTTPS 才能放开麦克风）

部署里有**两套**隧道实现，按镜像可用性选用：

- `start_all.sh`：检测到 **cpolar** 则 `cpolar http 8001` 起临时隧道（国内直连，免 authtoken 不启）；
  免费版域名每次重启会变，以 `logs/cpolar.log` 里的新地址为准；
- `resume.sh`：用 **cloudflared(cfd)** 快速隧道 `cfd tunnel --url http://127.0.0.1:8001`，
  打印 `https://*.trycloudflare.com` 并写入 `logs/public_url.txt`。

学生端入口：`http://<公网域名>/app/subject_select/`。

## 六、本地 ↔ 云端（开发期工具，新增）

用 SSH(paramiko) 在本地与云机之间同步代码、控制引擎，无需登云：

```bash
# 1) 增量同步本地 → 云端（只增不删；跳过 .venv/日志/缓存/.env）
python scripts/sync_cloud.py            # 增量
python scripts/sync_cloud.py --dry      # 预览将上传哪些文件
python scripts/sync_cloud.py --force    # 全量重传
#   PowerShell 版：powershell -File scripts\sync_cloud.ps1

# 2) 远程控制云端引擎（SSH 执行）
python scripts/cloud_ctl.py status      # 引擎进程 + 健康
python scripts/cloud_ctl.py restart     # 重启 MuseTalk 引擎
python scripts/cloud_ctl.py restart_app # 重启主应用
python scripts/cloud_ctl.py restart_all # 引擎 + 主应用
python scripts/cloud_ctl.py health      # 主应用 + 引擎健康
python scripts/cloud_ctl.py public      # 取当前 cpolar 公网地址
python scripts/cloud_ctl.py exec "ls -la"

# 3) 本机主应用 + SSH 隧道调用云端引擎（数字人只跑在云上）
powershell -ExecutionPolicy Bypass -File scripts\start_cloud.ps1
#   -Stop 停止；-NoEngine 只起隧道+应用
```

连接信息用环境变量覆盖：`CLOUD_HOST / CLOUD_PORT / CLOUD_USER / CLOUD_PWD / CLOUD_ROOT`。

## 七、验证与排错

```bash
curl http://127.0.0.1:8001/health            # 主应用
curl http://127.0.0.1:8100/v1/models         # 答疑大脑（本地 AWQ / vLLM；在线 API 时无此项）
curl http://127.0.0.1:10095/health           # FunASR
curl http://127.0.0.1:8090/health            # CosyVoice（返回 version=3 表示已切到 CosyVoice3）
curl http://127.0.0.1:8012/health            # MuseTalk
python -m scripts.run_demo                   # 不依赖引擎的 1对1 答疑自检（Mock 降级）
```

| 现象 | 排查 |
| --- | --- |
| 某引擎 `[WAIT]` | 看 `deploy/cloud/logs/<引擎>.log`；多为权重没下全或 CUDA/torch 版本不匹配 |
| 答疑是占位回复 | 在线：`LLM_API_BASE/KEY` 没填对；离线：本地 AWQ 引擎没起或 `LLM_API_BASE` 没指向 `127.0.0.1:8100` → 降级 MockLLM |
| 有声音无对口型视频 | MuseTalk 引擎没起，或 TTS 无音频（CosyVoice 未起）→ 回退照片木偶 |
| 某学科老师不出画 | 该学科 `data/teachers/<key>/talk.mp4` 缺失 → 引擎懒加载失败；补齐后 `_restart_engine.sh` |
| 老师音色不对 | `teacher.json` 的 `voice` / `voice_engine` 未配或 `voice_ref.wav` 缺失 → 回落 edge 兜底音色 |
| 显存 OOM | 用在线答疑大脑或更小 AWQ；减 `MUSETALK_MAX_TEACHERS` / `MUSETALK_BATCH`；vLLM 降 `VLLM_GPU_MEM_UTIL` |
| 外网访问不了 8001 | 云安全组放行端口；或 `ssh -L 8001:127.0.0.1:8001 ...`；或改用 cpolar/cloudflared 隧道 |
| 改了代码不生效 | 旧进程占端口（重启脚本按 `/proc` 匹配）；用 `restart_app.sh` 而非手动 kill |

### 已知兼容性问题（优云智算 py3.12 镜像实测）
- **CosyVoice(2/3) / MuseTalk 环境在该镜像（Python 3.12 + torch 2.13）上难以构建**：
  其 requirements 锁定大量老版本（`torch==2.3.1`、`deepspeed`、`tensorrt-cu12`、`openai-whisper==20231117`、
  `pyworld`、`grpcio==1.57.0` 等），与新 setuptools（已移除 `pkg_resources`）及 Python 3.12 冲突。
- **现方案**：`start_all.sh` 优先复用平台 **conda 环境**（TTS 用 `cv310`、MuseTalk 用 `mt310`，均已验证可跑），
  环境不在时才回退 `.venvs/*` 现场重建；构建期统一约束 `setuptools<81`（见 `constraints.txt`）。
- **TTS 兜底**：`TTS_PROVIDER=edge`（edge-tts，免依赖）可保证全链路可跑；
  `AVATAR_BACKEND=musetalk` 在引擎未起时会自动降级。
- **要真跑 CosyVoice/MuseTalk**：建议用匹配镜像（如 Python 3.10 + CUDA 12.1 + torch 2.3），
  或对 sdist 依赖用 `pip install --no-build-isolation -r <req>`。

## 八、优云智算（及同类平台镜像）适配说明

平台镜像（如 `cuda132_torch2130_py312`）**已预装 torch + CUDA**，本套脚本已适配：

1. **开机先自检**：`bash deploy/cloud/check_gpu.sh`——验证 torch 认得 GPU、compute capability、一次 CUDA 矩阵乘。**V100=sm_70**；若 torch 不含该架构 kernel 会报错，换镜像再继续。
2. **venv 继承平台 torch**：`setup.sh`/`start_all.sh` 建 venv 默认 `--system-site-packages`，装仓库 requirements 时过滤 torch 行，不重复下载/不覆盖平台 torch；完全独立安装用 `INHERIT_SYSTEM=0`。
3. **attention 后端自适应**：`start_all.sh` 检测 `gpu_major<8`（如 V100 sm_70）时自动装 xformers 并设 `VLLM_ATTENTION_BACKEND=XFORMERS`；**4090(sm_89)/A100(sm_80+) 则原生 FlashAttention，无需回退**。
4. **PATH 兜底**：AutoDL 等把 `python3` 放在 `/root/miniconda3/bin` 却不在默认 PATH 里，脚本会自动补 PATH，避免「只起来主应用、引擎全没起」。

**推荐机型**：**RTX 4090 48G ×1**（sm_89，全栈同驻 + 在线答疑大脑）；预算紧选 V100S 32G（在线答疑或 AWQ + xformers 回退）。
