# 本地开发与联调

## 环境
- Python 3.10+
- 建议虚拟环境：`python -m venv .venv && .venv\Scripts\activate`（Windows）

## 安装
```bash
pip install -e .                 # 核心依赖
pip install -e ".[vision]"       # + MediaPipe / OpenCV（数字人人脸检测）
pip install -e ".[ocr]"          # + PaddleOCR（真实 OCR）
pip install -e ".[dev]"          # + pytest / ruff
```

## 配置
复制 `.env.example` 为 `.env` 并按需填写。**留空即自动 Mock 降级**：
- `LLM_API_KEY` 空 → `MockLLM`
- `ASR_*` / `TTS_*` 空 → `MockASR` / `MockTTS`
- `OCR_PROVIDER=paddle` 但未装 paddleocr → `MockOCRClient`

## 运行
```bash
# 离线全链路演示（推荐先跑通这个）
python -m scripts.run_demo

# 数据目录初始化（示例文件已随仓库提供）
python -m scripts.seed_data

# 启动实时服务
python -m server.app           # 或 education-server
```

- 学科选择页（入口）：http://localhost:8000/
- 1v1 辅导页：http://localhost:8000/app/student_tablet/（带 `?subject=数学` 进入辅导课模式）
- 监控台：http://localhost:8000/app/teacher_web/
- 健康检查：http://localhost:8000/health
- 学科清单：http://localhost:8000/api/subjects
- 辅导课策略：http://localhost:8000/api/course/policy

## WebSocket 协议（`/ws`）

上行（客户端 → 服务端）：
```jsonc
{"type":"init","student_id":"stu-1","session_id":"可选","subject":"数学"}
{"type":"course_start","subject":"数学"}             // 进入辅导页：触发教师主动打招呼
{"type":"course_phase","phase":"lecture"}           // 前端计时器到点上报（opening/lecture/interaction/summary/ended）
{"type":"quiz_request","topic":"一元一次方程"}       // 手动要求再出一道模拟题
{"type":"text","text":"这道题怎么算？"}
{"type":"image","image_id":"img-1","data":"data:image/jpeg;base64,..."}
{"type":"voice","data":"<base64 audio>"}
{"type":"vad","has_voice":true,"ts_ms":1710000000000}
{"type":"ping","ts":1710000000000}
```

下行（服务端 → 客户端）：
```jsonc
{"type":"ready","payload":{"session_id":"..."}}
{"type":"status","payload":{"mic_state":"student_silent","ai_running":true}}
{"type":"course_state","payload":{"subject":"数学","phase":"lecture","phase_label":"知识点讲解","duration_seconds":2400,"active":true}}
{"type":"ai_quiz","payload":{"qid":"quiz-1","type":"choice","question":"...","options":["A","B"],"index":1}}
{"type":"board_ops","payload":[{"op":"text","x":0.08,"y":0.12,"text":"1. ...","seq":3}]}
{"type":"chat_message","payload":{"role":"ai","text":"..."}}
{"type":"ai_speech","payload":{"text":"...","mood":"greeting"}}   // mood: greeting/speaking/thinking/praising/waiting
```

## 1v1 辅导课流程（新增）

```
学科选择页 /  →  ?subject=<学科>  →  1v1 辅导页
   │                                    │
   │                      init(subject) + course_start
   │                                    ▼
   │                        教师打招呼（mood=greeting / gesture=greet，挥手）
   │                                    ▼
   │                学生提问 → 讲解（mood=speaking，白板分步）
   │                                    ▼
   │                自动出模拟题（ai_quiz，mood=waiting）
   │                                    ▼
   │                学生作答 → ai_check 判题（答对 mood=praising）
   │                                    ▼
   └──────────────────  总结答疑（倒计时结束 / 手动「结束辅导」）
```

- 阶段由**前端倒计时**驱动（`/api/course/policy` 下发总时长与阶段划分），后端只做
  「时间 → 阶段」映射与过渡话术，不引入长驻定时器，避免与会话循环二次调度冲突。
- 出题/判题**复用既有追问链路**：题目写入 `pending_question`，学生作答经
  `_should_treat_as_answer` → `_turn_answer_check` 自动判题、给提示与纠错。
- 学科元数据在 `config/subjects.py`（新增学科只改这一处）；阶段配置在 `config/constants.py`
  的 `TUTOR_PHASE_*`；开关 `COURSE_ENABLE / COURSE_DURATION_MINUTES / COURSE_QUIZ_ENABLE`。

## 分享给他人使用（局域网 / 公网 HTTPS）

页面本身是**与域名无关**的：WebSocket 用 `location.host` 动态推导，静态资源全部走绝对路径
（`/app/...`、`/media/...`），所以同一份页面在 `127.0.0.1`、局域网 IP、公网域名或 HTTPS 隧道下都能直接跑。

前提与分工：

| 项 | 说明 |
| --- | --- |
| 服务监听 | `.env` 的 `HOST=0.0.0.0`（默认）即可被外部访问，无需改动 |
| 模型调用 | LLM / ASR / TTS 全在**服务端**调用云端，访问者**不需要任何 Key** |
| 谁在付费 | 访问者的每次提问都会消耗**服务端配置的** LLM / ASR 额度 |
| 并发 | 每条 WebSocket 连接一个独立会话（`SessionStore` 内存态），小规模多人同时用没问题 |

### 方式一：同一局域网（最快，但只能文字提问）

```bash
# 查本机局域网 IP（Windows）
ipconfig
# 访问者打开： http://<你的局域网IP>:8001
```

> ⚠️ **浏览器硬限制**：`http://` 且非 localhost 属于**非安全上下文**，浏览器会禁用
> `getUserMedia`（麦克风/摄像头）。因此**语音提问、语音对话、拍照上传、摄像头预览不可用**，
> 但**文字提问完全正常**（AI 都在服务端）。
> 这种情况下页面会自动显示提示横幅并禁用相关按钮，不会出现「点了没反应」。

### 方式二：公网 HTTPS 隧道（语音 + 拍照全部可用，推荐）

```bash
# cloudflared：免费、自动签发证书、无需开端口/备案
cloudflared tunnel --url http://127.0.0.1:8001
# 输出形如 https://xxxx.trycloudflare.com，直接发给访问者即可
```

同类方案：`ngrok http 8001`、或自建 Nginx/Caddy 反代 + 证书。

HTTPS 下 `getUserMedia` 与 `SpeechRecognition` 均可用，即**语音提问、语音对话、拍照上传、摄像头预览全部恢复**。

### 其他注意

- **无登录校验**：拿到链接的人都能用；如需限制，可加访问码（在 `.env` 增 `ACCESS_CODE` 并在
  WebSocket `init` 校验，或直接放在反向代理的 Basic Auth 之后）。
- **数字人嘴型**：`AVATAR_BACKEND=http` 指向本机渲染引擎（默认 `127.0.0.1:8011`）。
  未启动引擎时会自动降级为「照片木偶」（有声音、口型为近似开合），不影响提问与讲解。

## 常见问题
- **摄像头/麦克风无法启动**：需 HTTPS 或 localhost（安全上下文），否则浏览器直接禁用；
  非安全上下文下页面会显示提示横幅并禁用相关按钮，文字提问不受影响。
- **别人打不开我的页面**：确认 `HOST=0.0.0.0`、防火墙放行 `PORT`、访问者与你在同一网络（或改用 HTTPS 隧道）。
- **SQLite 文件位置**：默认生成在运行目录 `education.db`，已在 `.gitignore` 忽略。
