# 待补齐与后续规划（Backfill Plan）

> 本文件记录 1对1 实时答疑教学 AI 的待补齐项与后续规划（按 P0-P2 优先级）。
> 各项均以「不改变对外接口、用真实能力替换 Mock」为原则推进。

## P0 · 让真实能力替换 Mock（不改变接口）
- [ ] **流式语音链路**：接入流式 ASR + 服务端 VAD + 流式 TTS，
      在 `models/asr.py` / `models/tts.py` 增加 `stream_*` 方法，backend 切 FunASR / CosyVoice 3·GPT-SoVITS，
      在 `core/loop.py` 增加音频分片入口。当前为「音频片段 → 整段 ASR」。
- [ ] **WebRTC 音视频**：引入 SFU（Agora / LiveKit / 声网 / 即构），
      `clients/student_tablet` 用 RTC SDK 替换 `getUserMedia + WebSocket`；
      服务端新增 `/api/rtc/token` 签发房间令牌（`RTC_APP_ID/SECRET`）。
- [ ] **图片圈画定位**：由 VLM 返回题目 bbox 或 OCR 行框，
      替换 `TeacherAgent.answer_image` 中的固定区域示意。

## P1 · 产品化增强
- [x] **错题写入长期记忆**：判题首次答错即写入 `core/memory`（`data/memory/students/<id>.jsonl`），
      下次这位学生上课时自动注入讲解；支持停用 / 恢复 / **整份删除**（`/api/memory*`）。
      *已完成的部分*：写入、注入、隔离与删除；`MEMORY_DISTILL_ENABLE` 默认关（省额度）。
- [ ] **错题本闭环（后半段）**：按错题自动**推送同类题**（需题库按知识点打标 + 组卷策略），
      并把错题落 `db.wrong_book` 以便跨设备查询（`core/homework_mode.py` 已预留接口）。
- [ ] **作业模式接通**：前端增加「作业模式」入口，串联 `HomeworkSession`
      与 `HomeworkHintPolicy`（分层提示：概念→方法→步骤→答案）。
- [ ] **学习画像报表**：基于 `LongTermMemory.profile()` 输出薄弱点趋势。
- [ ] **监控台完善**：`clients/teacher_web` 增加实时会话列表与答疑质量抽检接口。

## P2 · 工程与可靠性
- [ ] **持久化会话**：`SessionStore` 从内存切换 Redis，支持多实例水平扩展。
- [ ] **可观测性**：接入 Prometheus 指标（首响时延、LLM 熔断次数）
      与分布式链路追踪。
- [ ] **鉴权**：WebSocket 握手接入 `AntiRevGuard.verify` 签名与 JWT 鉴权。
- [ ] **回放与审计**：白板指令流落库，支持课后回放（`checkpoint` 已存快照）。

## 已知取舍
- 检索为 bigram 轻量实现，数据量增大后建议迁移向量库（`rag/`）；学情记忆的相关性检索同此。
- **ReAct 闭环与流式话术互斥**：开启 `AGENT_REACT_ENABLE` 后老师要先把题算完再开口，
  牺牲并行流式省下的那几秒首响（换来的是「先复核再讲」）。要极限首响就关掉它，
  详见 [`../docs/agent_autonomy.md`](../docs/agent_autonomy.md) §3。
- **坐标级白板工具不暴露给模型**：板书版式由确定性布局器负责，模型只给内容不给坐标
  （MCP 对外仍暴露 `whiteboard_write`，供外部 agent 使用）。
