# tests/skills — 技能类测试

与 `core/skills/` 对应的测试子目录（按被测模块分组，便于扩展）。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `__init__.py` | 包声明。 |
| `test_expression_skill.py` | 表情技能测试：情境判定（一般答对 / 表现出色）、`_SKIP_HINTS` 对疑问/求助/寒暄的拦截、未命中时**不拦截**正常答疑链路。 |
| `test_agent_skills.py` | Agent 技能测试：技能以 function calling 暴露、经 `AgentToolkit` 调用与降级、未命中可读、**自我更新**（经验附加进技能上下文 / 裁决回写战绩 / 按开关自动停用）、开关可关、端到端接线（回合末战绩落盘）。 |

## 设计要点

- **技能只做加法**：测试显式验证「未命中返回 None、正常走答疑」这一契约，防止技能演进成路径上的拦截器。
- **接线要有证据**：`test_agent_skills.py` 的端到端用例直接跑 `Supervisor.handle_turn`，
  验证「模型调了技能 → 战绩落盘」—— 本项目已有「模块写完、测试也在、就是没接进链路」
  的反面教材（`expression_skill` 曾经就是），因此每个新能力都必须有一条接线证明。
- **补齐约定**：`core/skills/` 后续新增技能时，测试放进本目录（与顶层 `tests/test_*.py` 的按主题分组互补）。
