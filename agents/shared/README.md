# agents/shared — 跨 Agent 共用件

被 TeacherAgent / LecturerAgent / Supervisor 共用的基础能力：麦控、白板、提示词装配、工具包、重点标红、回复解析。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `__init__.py` | 包门户。 |
| `mic_control.py` | 智能麦控状态机：VAD 驱动 `MicState` 迁移，学生开口 AI 静默、静默后触发答疑、支持 barge-in 打断判定。 |
| `whiteboard.py` | 白板指令构造与排版：文字 / 绘图 / 圈画 / 高亮 / 清屏，坐标归一化与防重叠排版。 |
| `teaching_layers.py` | **提示词装配层**：共享层（身份基座 / 学科与学段 / 讲课风格 / 老师人格 / 学科人格 / 经验层）+ 任务契约（由调用方传入）。答疑与讲课都从这里取，保证「同一位老师」。 |
| `toolkit.py` | Agent 工具集：把知识检索 / 解方程 / 验算 / OCR 读题 / 读白板 暴露给模型自主调用（`AGENT_TOOLS_ENABLE`）。 |
| `emphasis.py` | 重点标记：`**...**` 的解析与剥离；语音/聊天文本下发前必先 `strip_emphasis`，前端只拼 DOM 节点渲染标红（不用 innerHTML）。 |
| `reply_parser.py` | LLM 回复的 JSON 归一化：把模型返回文本里的 JSON 抠出来解析为 dict，不感知任何字段（契约解释留在各 agent）。 |

## 设计要点

- **标记用「文字内标记」而非独立字段**：重点是**片段**（「移项要**变号**」只有两字该红），独立字段无法定位到句中位置，只能整行标红——整行红等于没有重点。
- **两个必守性质**（`emphasis.py`）：`**` 绝不进语音（TTS 读出来很怪）、绝不进 HTML（模型产出属不可信文本，必须走 DOM 节点）。
- **提示词分层边界写死**：共享层不认识任何具体输出字段，任务契约一律由调用方传入——避免了拆分前「答疑 JSON 契约和课件契约塞进同一个 system，模型只能猜」的问题。
- **工具调用由模型拿主意**：工具集只负责按需执行与结果回填（`ToolCall.raw` 原样回填，防漏字段），是否调用由 ReAct 闭环现场决定。
